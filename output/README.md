# oh-my-posh

A prompt theme engine for any shell — bash, zsh, fish, PowerShell, and more.

This package installs the `oh-my-posh` binary and every built-in theme under
`/usr/share/oh-my-posh/themes/`. Initialize it in your shell, e.g. for bash:

```bash
eval "$(oh-my-posh init bash --config /usr/share/oh-my-posh/themes/jandedobbeleer.omp.json)"
```
